# Player test

The instrument is accepted by a stranger, not by its author (engine ROADMAP decisions on simplicity, 13 and 21). Run this on the first build and on every build that changes what a slider or a species does.

## Protocol

1. The first person who is not the author. Five minutes. Nothing explained beyond "touch to start".
2. **Pass one, unlabelled.** Menu, Player test, uncheck "Show control labels". Hand it over.
3. **Pass two, labelled.** Check the labels. Hand it over again.
4. After each pass, ask the three questions and write the answers down verbatim.
5. File each answer that touches the engine as an issue on the engine repo, one per request, with the player's need in the first line.
6. If the unlabelled pass names a slider better than growth, bloom, roots, mold or bacteria, note it here: that is a candidate name for engine 2.0.

## The three questions

1. What did the sliders do?
2. Which sound was which?
3. Would you keep going?
